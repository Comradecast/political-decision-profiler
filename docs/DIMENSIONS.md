# Dimension Definitions (V1.1)

This system uses a 7-dimension model split into two layers:

## Layer A: Values (What should happen)

### 1. Market Preference

Who should allocate resources?

* 0 → Government-directed
* 100 → Market-driven

**Rule:** Measures coordination mechanism only.
Must not include fairness, trust, or intervention timing.

---

### 2. Decision Authority

Where should decision-making authority reside?

* 0 → Centralized (federal/state authority)
* 100 → Decentralized (local/individual control)

**Rule:** Always framed as “who should decide,” not “what is best.”

---

### 3. Fairness Preference

What defines fairness?

* 0 → Equal outcomes
* 100 → Equal opportunity

**Rule:** Must not include efficiency, growth, or trust framing.

---

## Layer B: Decision Behavior (How decisions are made)

### 4. Risk Tolerance

How much disruption are you willing to accept?

* 0 → Stability / protection
* 100 → Competition / disruption

**Rule:**

* Must assume known outcomes
* Must NOT include uncertainty or intervention language

---

### 5. Time Horizon

When should outcomes be optimized for?

* 0 → Immediate results
* 100 → Long-term outcomes

**Rule:**

* Must include present cost + delayed payoff
* Must avoid risk framing

---

### 6. System Trust

Do you believe systems function as intended?

* 0 → Low trust
* 100 → High trust

**Measured across:**

* Government
* Corporations

**Rule:**

* Always framed as belief about reality
* Never framed as preference

---

### 7. Intervention Style

When should action be taken?

* 0 → Proactive / preventative
* 100 → Reactive / hands-off

**Rule:**

* Must include uncertainty or incomplete information
* Must NOT measure risk tolerance or authority

---

## Critical Separation Rules

1. Never mix “should” (values) and “do you believe” (trust)
2. Separate accepting outcomes (risk) from causing action (intervention)
3. Keep time horizon independent of risk
